ענבר פרחי = מומחית לטיפוח כף הרגל (לא רפואית).

מילים אסורות בכלל הטקסטים והכותרות (AI generation + copy ידני):
- "רפואי/ת/ים/ות"
- "קליני/ת/ים/ות"
- "פדיקור רפואי" (אין הסמכה רגולטורית כזו בישראל)
- "השרייה במים" / "השריית רגליים" / "אמבט רגליים" (מזיק לעור ולציפורן)
- "ניתוח", "כירורגיה", "מינון", "מרשם", "תרופה", "אבחנה", "אבחון"
- "מטופל/ת" → "לקוחה" / "פונה"
- "מרפאה" → "קליניקה" / "סטודיו"
- "פרא-רפואית", "מומחית רפואית"

אימות עובדות: הצלבה בין לפחות 3 מקורות מורשים בלתי תלויים מהרשימה (health.gov.il, gov.il, kolzchut, קופות חולים, Mayo Clinic, NHS, CDC, WHO, NIH, MedlinePlus, PubMed, Cochrane, BMJ, NEJM, JAMA, Lancet, BJSM, APMA, IWGDF, AAOS, NICE). פורומים/בלוגים/Reddit אינם מקור.

לפחות 2 מתוך 3-7 sources חייבים להיות ישראליים (משרד הבריאות / קופ"ח / כל-זכות) או NHS/Mayo/NIH.

מצבים שמחייבים רופא (סוכרת, פצע, זיהום, חשד גידול): הפניה ברורה לרופא, לא הוראות טיפול.

**Why:** מניעת חריגה מסמכות מקצועית, התאמה רגולטורית בישראל, והגנה משפטית.
