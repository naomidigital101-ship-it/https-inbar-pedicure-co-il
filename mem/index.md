# Project Memory

## Core
שפה: עברית RTL, גופנים Heebo (גוף) + Frank Ruhl Libre (כותרות). אסור Arial/Roboto/Inter.
Stack: React + Vite + Tailwind + shadcn/ui + Lucide. TS strict, אסור any, named exports בלבד.
SEO: title/description/canonical ייחודיים לכל עמוד, H1 יחיד, alt בעברית, Schema.org.
תמונות AI עם טקסט עברי: הטקסט חייב להיות מושלם ומדויק בלי שגיאות כתיב. אם לא בטוח — בלי טקסט בתמונה.
המחשה ויזואלית: כל מושג/כלי שמוזכר במאמר (מפתח אלן, ברגים, חלקים) חייב להיות מומחש בתמונה/שרטוט/אייקון.
אסור מקף ארוך (—) או סימנים מזהי AI בטקסטים.
Backend: Lovable Cloud (Supabase). מאמרים נשמרים ב-src/lib/articles.ts + src/lib/articles-content/.
תחום: טיפוח כף הרגל (לא רפואי). אסור: "רפואי", "קליני", "פדיקור רפואי", "השרייה במים", "אמבט רגליים", "מטופלת", "מרפאה", "מינון", "אבחון", "ניתוח".
אימות עובדות: הצלבה בין 3+ מקורות מורשים (health.gov.il, קופ"ח, Mayo, NHS, NIH, PubMed, Cochrane, APMA, IWGDF). פורומים אינם מקור.
