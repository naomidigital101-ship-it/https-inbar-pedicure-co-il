
# שדרוג עמוד הבית לרמת הליטוש של ד"ר לוינגר

המטרה: לאמץ את **המבנה, ההיררכיה, הריווח, רמת הצילום והקומפוזיציה** של drlevinger.co.il — אבל לשמור על זהות המותג של ענבר (קרם חם, ירוק־סייג', נחושת, Frank Ruhl Libre). זו לא חיקוי פלטה, זו העלאת רף הליטוש.

הטיפול הוא רק ב-`src/routes/index.tsx` (עמוד הבית) ובכמה רכיבים תומכים. שאר העמודים — לא נוגעים.

---

## מה שונה אצל לוינגר ועובד

1. **Hero אסימטרי-קולנועי** — דמות הרופא ממלאת את כל ימין המסך (ב-RTL) ב-fade עדין לרקע, במקום להיות "כרטיס תמונה". הכותרת ממורכזת אופטית, גדולה, רגועה.
2. **שלישיית כרטיסי-פלגשיפ** — שלושה כרטיסים גדולים, כל אחד עם תמונה איכותית + רצועת כותרת מלאת־צבע בגוון אחר (כחול בהיר, בינוני, כהה). זה ה-CTA הוויזואלי החזק של הדף.
3. **סרגל חיפוש/סינון** שצף מתחת לכרטיסים — "מצאי טיפול לפי תחום / קופה / סוג". מרגיש כמו ממשק קליני אמיתי, לא דף שיווקי.
4. **לוגו עם תת־כותרת מותגית** בפינה (ענבר פרחי / "קליניקה לבריאות כף הרגל").
5. **לשונית CTA צפה בצד** — "לתיאום פגישת ייעוץ" בעיגול קבוע בצד שמאל למעלה.
6. **ריווח נדיב מאוד** — כל סקשן נושם, אין דחיסות.

## מה משנים בקובץ `src/routes/index.tsx`

### 1) Hero חדש — Cinematic Authority
- מחליפים את גריד ה-7/5 הקיים ב-hero בגובה `min-h-[88vh]` עם תמונת ענבר כ-`<img>` מוחלט בצד ימין (`absolute inset-y-0 right-0 w-[60%]`), עם מסכת gradient משמאל אל קרם הרקע (`bg-gradient-to-l from-transparent via-background/80 to-background`) כדי שהטקסט יישב בנוחות.
- הכותרת ממורכזת אנכית בצד שמאל-מרכז: kicker נחושת קטן, שני שורות כותרת ענקיות (`text-[5.5rem]`) — שורה ראשונה רגילה, שורה שנייה ב-`display-italic` בירוק־סייג'.
- מתחת — פסקה אחת רגועה, ואז שני CTAs צמודים: ראשי (ירוק־סייג' מלא, "לתיאום פגישה") + משני (outline נחושת, "מאסטרקלאס לפדיקוריסטיות").
- שורת stats שלישונית `+150 / +20 / +12` מתחת ל-CTAs בטיפוגרפיה דקה (לא תיבות עם רקע).
- ה-photo card הקיים (badge + halo + bottom proof tag) — יוצא לטובת התמונה ה"קולנועית".

### 2) שלישיית כרטיסי-פלגשיפ (חדש, אחרי ה-Hero)
3 כרטיסים בגריד שווה, כל אחד מציג טיפול־דגל בקליניקה:
- **פטרת ציפורניים** (הכי בולט — ירוק־סייג' עמוק על הרצועה)
- **ציפורן חודרנית / אורטוניקסיה** (סייג' בינוני)
- **פדיקור לחולי סוכרת / IWGDF** (נחושת)

כל כרטיס:
- תמונה רבועה למחצה (4:3) למעלה
- רצועת כותרת בגובה ~64px עם צבע מלא, טקסט לבן ממורכז ב-Frank Ruhl Libre
- בלחיצה — מוביל ל-`/services/{slug}` הרלוונטי
- hover: התמונה זוז עדינה (`scale-[1.03]`) והרצועה משתנה לגוון עמוק יותר

יוצרים `src/components/home/FlagshipCards.tsx`. נדרשות 3 תמונות חדשות (`imagegen--generate_image` — סגנון קליני, ידיים/כלים/כף רגל מקרוב, **בלי טקסט בתמונה**, פלטה קרם־ירוק):
- `flagship-fungus.jpg`
- `flagship-ingrown.jpg`
- `flagship-diabetic.jpg`

### 3) סרגל חיפוש/סינון צף (חדש)
מתחת לכרטיסי הפלגשיפ — בר אופקי על רקע `surface` עם shadow-lift, מרים מ-2cm מעל הסקשן הבא (`-translate-y-1/2` יחסי). שלושה Select עברית + כפתור "מצאי טיפול":
- "כל התחומים" / "פטרת" / "ציפורן חודרנית" / "סוכרת" / "אורטוניקסיה" / "BIO" / ...
- "סוג מטופל" / "מבוגרים" / "חולי סוכרת" / "ספורטאים" / "חיילים"
- "מה מטריד אותך?" / "כאב" / "פטרת" / "סדקים" / "ציפורן" / ...

הכפתור פשוט מנווט ל-`/services/{slug}` המתאים (סלקטור פשוט, בלי backend). יוצרים `src/components/home/TreatmentFinder.tsx` עם shadcn Select.

### 4) לשונית CTA צפה (חדש)
עיגול קבוע בצד שמאל למעלה (`fixed top-32 left-0 z-40`) — רקע ירוק־סייג' עמוק, טקסט לבן זקוף, "לתיאום פגישת ייעוץ", עם רדיוס רק בצד החיצוני. נראה מתחת ל-StickyWhatsApp הקיים אבל בצד הנגדי. רכיב חדש: `src/components/shared/ConsultationTab.tsx`. מוצג רק מ-`lg:` ומעלה.

### 5) Header — לוגו עם תת־כותרת
ב-`src/components/shared/SiteHeader.tsx`: מוסיפים מתחת ל-`SITE.brand` שורה קטנה אפורה — "קליניקה לבריאות כף הרגל". מקטינים את הסגנון של הלוגו מ-2xl ל-xl כדי שהבלוק יישב יפה. שאר ה-nav נשאר.

### 6) שאר הסקשנים של עמוד הבית
נשארים ברובם — רק מרווחים והיררכיה משתפצים כדי להתאים לרף החדש:
- כל `py-20 md:py-24` → `py-24 md:py-32`
- כל title section: kicker → רווח גדול יותר → H2 → רווח → פסקה תיאור
- מסירים את ה-`PartnersStrip` מעל סקשן `CONCERNS` ומעבירים אותו למטה (לפני ה-Footer) — כי הוא חלש אחרי ה-Hero החדש ושובר את הרצף הקולנועי.
- סקשן `CONCERNS` הופך לגריד 3x2 נקי יותר עם קווי מסגרת דקים בלבד (במקום cards מלאים), כדי שהפלגשיפ יישאר הכי בולט.

### 7) רקע ופרטים קטנים שמרימים את הליטוש
- מוסיפים noise/grain עדין מאוד לרקע ה-Hero בלבד (`.grain` הקיים כבר ב-styles.css — להפעיל).
- קו `1px` נחושת ברוחב 48px לפני כל kicker — כבר קיים ב-Hero, להחיל בעקביות בכל סקשן.
- כל הכפתורים — פינות `rounded-full` (כבר ככה), עם `transition` 300ms ו-`active:scale-[0.98]`.

## טכני קצר

- כל הקבצים החדשים: TypeScript strict, named exports, אסור `any`.
- צבעים — דרך tokens של `src/styles.css` בלבד (אסור hex/rgb בקומפוננטות).
- RTL נשמר (`dir="rtl"` הקיים).
- SEO/meta של ה-Route לא משתנים — נשארים כמו שהם.
- `head()`: לעדכן את `og:image` לתמונה החדשה של ה-Hero (אותה תמונת ענבר).
